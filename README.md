# ピッチ補正ツール

スマホ単体・完全オフラインで動くリアルタイム・ボーカルピッチ補正ツールです。
サーバーへの音声送信は一切なく、すべての処理はブラウザ内（Web Audio API）で完結します。

## 使い方

1. `index.html` を HTTPS（または `localhost`）でホストして、スマホのブラウザ（Chrome / Safari）で開きます。
2. キーとスケールを選び、「マイク開始」をタップします。
3. ハウリングを防ぐため、イヤホン・ヘッドホンの使用を推奨します。
4. 「補正の強さ」「補正スピード」で効きの強さを調整できます。

ホーム画面に追加すると PWA として動作し、次回以降はオフラインでも起動できます。

## 仕組み

- **ピッチ検出**: YIN アルゴリズムでマイク入力の基音周波数をリアルタイム推定
- **音程補正**: 検出した音を選択中のキー/スケールで最も近い音に量子化し、目標周波数を算出
- **ピッチシフト**: フェーズボコーダー（位相ボコーダー）方式で、AudioWorklet 上でリアルタイムに音声のピッチをシフト

## ローカルでの動作確認

```sh
python3 -m http.server 8000
# http://localhost:8000 をスマホ/PCのブラウザで開く
```

マイク入力を伴う機能のため、`localhost` 以外でホストする場合は HTTPS が必須です。
