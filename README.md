# 手動ピッチエディタ

スマホ単体・完全オフラインで動く、音符ごとに手作業でピッチを編集するツールです。
サーバーへの音声送信は一切なく、すべての処理はブラウザ内（Web Audio API）で完結します。

## 使い方

1. `index.html` を HTTPS（または `localhost`）でホストして、ブラウザ（Chrome / Safari）で開きます。
2. 音声ファイル、または動画ファイル（音声トラックを自動抽出）を選択します。
3. 自動でピッチを解析し、検出した音符ごとにブロックとして波形の上に表示します。
4. ブロックを上下にドラッグすると、その音符だけ半音単位でピッチを変更できます。
5. 「再生」ボタンや時間軸のタップで、編集を反映した音をその場でプレビューできます。
6. 「書き出す」を押すと、編集を反映した音声をダウンロードできます。

ホーム画面に追加すると PWA として動作し、次回以降はオフラインでも起動できます。

## 仕組み

- **波形表示**: 読み込んだ音声・動画のサンプルからピーク波形を描画
- **ピッチ検出**: YIN アルゴリズムでファイル全体の基音周波数を解析し、音符（ノート）単位に自動分割
- **手動編集**: 検出した音符ブロックをドラッグして、半音単位で目標ピッチを指定（ドラッグしない音符は無編集のまま）
- **プレビュー再生**: 「再生」ボタンまたは時間軸のタップで、編集内容を反映した音をその場で再生
- **書き出し**: フェーズボコーダー（位相ボコーダー）方式で、編集した音符の周辺だけにピッチシフトを適用してレンダリング。触っていない部分は元の音声データをそのまま使うため、音質は劣化しません
- **動画対応**: `decodeAudioData` で直接読めない動画は、`<video>` の `captureStream()` + `MediaRecorder` で音声トラックを抽出してから解析します（ブラウザによっては対応していない場合があります）

## ローカルでの動作確認

```sh
python3 -m http.server 8000
# http://localhost:8000 をブラウザで開く
```
