# 手動ピッチエディタ

スマホ単体・完全オフラインで動く、自由に選んだ範囲を手作業でピッチ編集するツールです。
サーバーへの音声送信は一切なく、すべての処理はブラウザ内（Web Audio API）で完結します。

## 使い方

1. `index.html` を HTTPS（または `localhost`）でホストして、ブラウザ（Chrome / Safari）で開きます。
2. 音声ファイル、または動画ファイル（音声トラックを自動抽出）を選択します。
3. 自動でピッチを解析し、実際の音程の動きを連続した曲線として波形の上に表示します。
4. 「範囲選択」をONにしてピアノロール上をドラッグすると、好きな範囲を自由に選べます。選択済みの範囲は長押しで選び直せます。
5. ▲▼ボタンで選択した範囲のピッチを半音単位で変更できます。
6. 「再生」ボタンや時間軸のタップで、編集を反映した音をその場でプレビューできます。
7. 「書き出す」を押すと、編集を反映した音声をダウンロードできます。

ホーム画面に追加すると PWA として動作し、次回以降はオフラインでも起動できます。

## 仕組み

- **波形表示**: 読み込んだ音声・動画のサンプルからピーク波形を描画
- **ピッチ検出**: YIN アルゴリズムでファイル全体の基音周波数を解析し、連続した曲線として表示（不安定な歌い方でも自動分割による途切れが起きません）
- **手動編集**: 「範囲選択」ツールでピアノロール上をドラッグして任意の時間範囲を選択し、▲▼ボタンで半音単位の目標シフト量を指定（選択・操作しない範囲は無編集のまま）。範囲選択モードのON/OFFで「ドラッグ＝スクロール」か「ドラッグ＝範囲指定」かを切り替えることで、スクロール操作とジェスチャーの競合を避けています。既存の範囲を選び直すときは長押しを使います
- **プレビュー再生**: 「再生」ボタンまたは時間軸のタップで、編集内容を反映した音をその場で再生
- **書き出し**: フェーズボコーダー（位相ボコーダー）方式で、編集した範囲の周辺だけにピッチシフトを適用してレンダリング。触っていない部分は元の音声データをそのまま使うため、音質は劣化しません
- **動画対応**: `decodeAudioData` で直接読めない動画は、`<video>` の `captureStream()` + `MediaRecorder` で音声トラックを抽出してから解析します（ブラウザによっては対応していない場合があります）

## ローカルでの動作確認

```sh
python3 -m http.server 8000
# http://localhost:8000 をブラウザで開く
```
